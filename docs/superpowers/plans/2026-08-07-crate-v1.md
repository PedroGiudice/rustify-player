# Crate v1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Busca e download da rede Soulseek dentro do app — view Crate: buscar → Baixar → a linha vira `▸ Tocar`, com staging, dedup e indexação automáticos.

**Architecture:** Crate Rust novo `slskd-client` (protocolo puro, testável offline contra fixtures reais), módulo `src-tauri/src/slsk/` (política: coordinator em thread única, JobBoard com escritor único, staging atômico via `.rustify-incoming`), extensões no `library-indexer` (`dedup.rs`, `IndexerCommand::IngestPaths` com reply channel), view SolidJS `Crate.tsx`.

**Tech Stack:** Rust (ureq, serde, crossbeam-channel, strsim, tempfile — já em workspace), Tauri 2 IPC, SolidJS + vitest.

**FONTE DA VERDADE:** `docs/superpowers/specs/2026-08-07-crate-in-app-downloads-design.md`. Este plano referencia seções da spec (§) — o executor DEVE ler a spec inteira antes da sua etapa. Onde plano e spec divergirem, o ADENDO DO SPIKE da spec prevalece (filename remoto com backslash; estados compostos por substring; localização por última-pasta+basename).

## Global Constraints

- Track IDs u64 viajam como STRING no IPC (`serialize_u64_as_string`, `types.rs:214`); nunca `as_i64` para IDs.
- CSS SOMENTE em `src/styles/extractor-lab.css` (components.css é órfão). Cores só via tokens de tema — nenhum hex literal.
- CSP (`tauri.conf.json` connect-src) NÃO ganha `:5030` — todo tráfego slskd via Rust.
- Credencial/JWT só em memória; `Debug` de `SlskAuth` redige a senha; nada em log/localStorage.
- Eventos Tauri em kebab-case (`slsk-jobs`); comandos `slsk_*` snake_case.
- Nome do módulo Rust: `slsk` (crate é keyword); rótulo de UI: **Crate**.
- Nunca panic por slskd fora do ar — badge/status, boot intacto.
- Nada é deletado do disco do usuário; colisão nunca sobrescreve.
- Gates por etapa: `cargo test --workspace` + `npm run typecheck` + `npx vitest run`. NENHUM `./scripts/release.sh` até o final de tudo.
- Commits atômicos por task, mensagem `feat(crate): ...` com trailers padrão.
